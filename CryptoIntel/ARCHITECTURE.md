# CryptoIntel 架构设计

## 📊 系统概览

CryptoIntel 是一个**模块化的加密项目情报系统**，包含两层核心功能：

1. **爬虫层** - 基于 Agent-Reach 架构的智能数据采集
2. **分析层** - 四维分析引擎，发现套利机会

## 🔧 技术栈

### 爬虫层

| 组件 | 技术 | 说明 |
|------|------|------|
| 框架 | Agent-Reach | 脚手架工具 |
| Twitter | twitter-cli | Cookie 认证 |
| Reddit | rdt-cli | Cookie 认证 |
| YouTube | yt-dlp | 无需认证 |
| Web | Jina Reader | 在线服务 |
| RSS | feedparser | 标准协议 |

### 分析层

| 组件 | 技术 | 说明 |
|------|------|------|
| 语言 | TypeScript | 类型安全 |
| 运行时 | Node.js | 跨平台 |
| 框架 | Next.js | Web界面 |
| AI | OpenAI/Claude | 评分和分析 |
| 数据库 | SQLite | 轻量级存储 |

---

## 📁 数据流

### 1. 数据采集

```
用户输入 → 爬虫调度器 → Agent-Reach Channels → 数据清洗 → 统一格式
```

### 2. 数据分析

```
原始数据 → AI 评分 (Step 1) → Blueprint 生成 (Step 2) → 机会列表
```

### 3. 结果输出

```
机会列表 → Web UI / CLI / API → 用户决策
```

## 🔌 扩展性

### 添加新平台

1. 创建新的 Channel 类
2. 继承 `Channel` 基类
3. 实现 `can_handle()` 和 `check()` 方法
4. 注册到 Channel Registry

### 添加新维度

1. 创建新的评分函数
2. 在 `DimensionScores` 接口中添加字段
3. 更新 `two-step-analyze.ts` Prompt
