# 简历优化懒人服务项目 - 完整背景与提示词

## 一、项目完整背景

### 1.1 项目起源

本项目基于**懒人服务**的商业模式创新：将GitHub上成熟的开源工具，包装成简单易用的在线服务，按次收费，让普通用户不需要技术能力就能使用这些工具。

**核心洞察**：
- 90%的人不会写代码、不会用命令行、不会配置环境
- GitHub上有大量成熟的开源工具（如reactive-resume、Resume-Matcher）
- 但这些工具的使用门槛很高，普通用户用不了
- **机会**：把这些工具包装成"懒人服务"，让用户花几块钱就能用

### 1.2 商业模式验证

**成功案例**：
- GitHub上的Whisper（音频转文字）→ 闲鱼挂单 ¥9.9/30分钟音频 → 大量订单
- 其他：Pandoc（文档格式转换）、Stable Diffusion（图片生成）等

**核心逻辑**：
- 成本：0（用免费开源工具）
- 壁垒：用户不知道背后是免费工具
- 利润：95%+（只需支付服务器和API成本）

### 1.3 市场分析

**目标用户**：
- 初级画像：找工作的程序员、社招求职者、跳槽的职场人
- 核心痛点：
  - 简历写不好，海投没回音
  - 不知道怎么突出自己的优势
  - 简历通不过ATS（Applicant Tracking System）系统筛选

**市场规模**：
- 中国每年3000万+求职者
- 程序员跳槽频率：1-2次/年
- 简历优化是刚需

**竞品分析**：
| 竞品 | 价格 | 模式 | 优势 | 劣势 |
|-----|------|------|------|------|
| Resume.io | $19.95/月 | 订阅制 | 功能全 | 贵，订阅压力大 |
| Zety | $29.99/月 | 订阅制 | 模板多 | 贵，订阅压力大 |
| 我们 | $9.9/次 | 按次收费 | 便宜，无压力 | 需持续优化 |

### 1.4 技术选型

**为什么选GitHub开源模块？**
1. 成熟可靠：Stars多，使用广泛
2. 代码质量高：经过大量测试
3. 社区活跃：更新迭代快
4. 文档完善：容易集成

**核心模块组合**：
1. **reactive-resume** (⭐38K) - 简历构建器，功能完善，开箱即用
2. **Resume-Matcher** (⭐27K) - ATS关键词优化，NLP模型
3. **Awesome-CV** (⭐27K) - LaTeX简历模板，专业美观
4. **ResumeSample** (⭐28K) - 中文简历模板，适配国内
