## 一、产品定位

**产品名称**：ResumePro（简历优化大师）

**核心价值**：让职场人花0.5 USDT，获得价值2000元的专业简历优化服务

## 三、技术架构

### 前端
- **框架**：React + TypeScript（基于reactive-resume）
- **UI库**：Tailwind CSS + shadcn/ui
- **简历模板**：5-10套精选模板（基于Awesome-CV + best-resume-ever）
- **PDF导出**：html2pdf.js / Puppeteer

### 后端
- **框架**：Next.js API Routes
- **数据库**：Supabase / PostgreSQL
- **文件存储**：Cloudflare R2 / S3
- **支付**：Stripe / LemonSqueezy

### AI能力
- **简历优化**：GPT-4 / Claude API
- **ATS检测**：Resume-Matcher的NLP模型
- **关键词匹配**：TF-IDF + 余弦相似度

### 部署
- **前端**：Vercel
- **后端**：Railway / Render
- **域名**：Namecheap / Cloudflare

## 四、产品功能

### 4.1 核心功能（Phase 1）

#### 功能1：AI简历生成
- **输入**：用户基本信息（姓名、工作经历、技能等）
- **处理**：GPT-4生成专业简历内容
- **输出**：结构化简历 + PDF文件

**定价**：0.5 USDT/次

#### 功能2：简历ATS优化
- **输入**：用户简历 + 目标JD
- **处理**：
  1. Resume-Matcher提取关键词
  2. 计算匹配度
  3. AI优化简历内容
- **输出**：优化后的简历 + ATS分数

**定价**：0.5 USDT/次

#### 功能3：简历模板
- **提供**：10套精选模板（程序员的简历）
- **特点**：
  - 简洁专业
  - 程序员友好
  - PDF高清导出
- **模板来源**：Awesome-CV + ResumeSample + best-resume-ever

**定价**：0.5 USDT/次（模板使用费）

### 4.2 增值功能（Phase 2）

#### 功能4：简历诊断报告
- **内容**：
  - 整体评分（0-100分）
  - 各模块分析
  - 优化建议
- **AI模型**：Claude API

**定价**：0.5 USDT/份

#### 功能5：求职信生成
- **输入**：简历 + JD
- **处理**：AI生成针对性求职信
- **输出**：专业求职信

**定价**：0.5 USDT/封

#### 功能6：职位匹配度分析
- **输入**：简历 + 多个JD
- **处理**：计算每个职位的匹配度
- **输出**：职位推荐列表 + 匹配度排名

**定价**：0.5 USDT/次
