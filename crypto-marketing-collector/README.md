# Crypto Marketing Data Collector

Collect crypto project marketing materials from official sources.

## Quick Start

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Configure environment variables
cp .env.example .env
# Edit .env with your API keys

# 3. Collect 100 samples (24-hour MVP)
python scripts/collect_100_samples.py
```
